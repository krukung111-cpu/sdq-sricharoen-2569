# SDQ Care ม.1 ปีการศึกษา 2569

โรงเรียนศรีเจริญศึกษา — ซอร์สโค้ดฉบับเต็ม React/Vinext + Cloudflare Workers + D1

เว็บใช้งานอยู่: https://sdq-sricharoen-m1-2569.krukung111.chatgpt.site

## ข้อมูลในสำเนานี้

ใช้รายชื่อและรหัสนักเรียนสมมติ 31 คน แทนข้อมูลนักเรียนจริง ไม่มีผลประเมินหรือสำเนาฐานข้อมูลใช้งานจริงรวมอยู่ใน Repository นี้
ก่อนใช้งานจริง ให้แทนที่ students ใน lib/data.json เฉพาะภายในเครื่องหรือ Repository ส่วนตัว ห้าม commit รายชื่อจริงใน Repository สาธารณะ

## ติดตั้ง

ใช้ Node.js 22 ขึ้นไปและ pnpm 11 ขึ้นไป

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

ต้องตั้งค่าฐานข้อมูล Cloudflare D1 binding ชื่อ DB และใช้ migrations ใน drizzle/ ก่อนบันทึกข้อมูลได้ การติดตั้งผ่าน Sites ต้องลงทะเบียนโปรเจกต์ใหม่และเพิ่ม project_id ที่ได้รับลงใน .openai/hosting.json

GitHub Pages ให้บริการไฟล์ static และไม่รัน API /api/records หรือ /api/settings ของแอปนี้ การฝากซอร์สใน GitHub จึงไม่ใช่การย้ายฐานข้อมูลหรือเปลี่ยนที่ให้บริการเว็บ
